## Replacement gate

Do not replace this placeholder with an old MailIQ recording and call it current. A valid current demo should show, at minimum:

1. one real onboarding/account path;
2. provider connection or a controlled provider-lifecycle path;
3. an inbound Gmail or Outlook event entering the system;
4. classification/extraction/routing through the appropriate processor;
5. authoritative account/message state being updated correctly;
6. at least one delivery/output path;
7. one failure/retry/reconciliation or operator-visible path;
8. the exact workflow/version set used in the recording.

The demo must be labelled with date, environment and limitations. It is evidence of the demonstrated configuration only, not automatically production/SLA evidence.
